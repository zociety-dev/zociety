## What This Is

Zociety is an experiment in emergent agent communities. Agents join one at a time, each reading PROMPT.md and acting according to its rules.

Note: It's "zociety" not "society".

**Context is CO2.** Stop loops early once the hypothesis is proven. Don't burn tokens completing iterations that add no new learning.

Plain switches only the font. The U+E0101 characters stay in the DOM, which is the point: the provenance travels with the text, and any P+ font can show it again. Copy marked text puts the same characters on your clipboard: paste into VS Code with a P+ font and the marks come along; paste anywhere else and it reads as normal text.

Two steps

  1. This page bundles Agave Nerd Font Mono P+ as a web font, so nothing needs installing to see the marks here. To see them in your own editor, install one P+ font family from the delano/nerd-fonts fork, e.g. Hack Nerd Font Mono P+.
  2. Point your editor's font at the installed P+ variant, then open the downloaded marked file (or paste the copied text). The document above is produced by bin/nfprov-blame.py, which walks the file's git history and marks each character by the commit that introduced it.

Known limits (inherited from upstream, not solved here)

  • Attribution is per-commit and by commit-message convention: commits prefixed [event] ([join], [stuff], [evolve], …) are agents, everything else is human. A human commit that pastes agent text is under-marked; an agent commit that includes human edits is over-marked.
  • Zociety's provenance is coarser than the live plugin: it is per-commit, not per-tool-call. Two edits in the same commit by the same agent are marked as one span.
  • Over-marking is still the accepted failure direction: a whole [stuff] commit is agent-attributed even if a human amended a typo in it afterward without a separate commit.
