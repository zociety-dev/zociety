🔤 Provenance Demo

Five-minute demo for delano/nerd-fonts#15: agent-written text made visibly distinct from human-written text, in an editor you already use, once a P+ font is installed.

Two steps

  1. This page bundles Agave Nerd Font Mono P+ as a web font, so nothing needs installing to see the marks here. To see them in your own editor, install one P+ font family from the delano/nerd-fonts fork, e.g. Hack Nerd Font Mono P+.
  2. Point your editor's font at the installed P+ variant, then open text marked by bin/nfprov-drive (or just read the example below — it's rendered by your browser with the bundled font).

Live example

The block below is the most recent addition to zociety's own LEARNINGS.md, run through bin/nfprov-drive LEARNINGS.md learnings. Every character zociety's agents added since the previous commit carries a provenance mark. The default vs mode inserts U+E0101 (VARIATION SELECTOR-18) after each character; NFPROV_MODE=pua mode maps each character into Supplementary PUA-B (U+100000 + codepoint) instead. The bundled P+ font renders the marks; any other font renders the plain glyphs, which is the expected fallback.

Known limits (inherited from upstream, not solved here)

  • Zociety's provenance is coarser than the live plugin: it is per-commit, not per-tool-call. Two edits in the same commit by the same agent are marked as one span.
  • Over-marking is still the accepted failure direction: a whole [stuff] commit is agent-attributed even if a human amended a typo in it afterward without a separate commit.
